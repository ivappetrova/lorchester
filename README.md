# Lorchester

Lorchester is a 3D side-scrolling platformer prototype built in Unity, developed as a university project for the Game Development course at Howest University of Applied Sciences in Kortrijk, Belgium.

You control two characters with different skill sets, switching between them to reach each floor's key, solve puzzles, and fight enemies along the way. Progress is gated by finding the key on each level to unlock the path to the next floor.

## About

- **Engine:** Unity 2022.3.62f3
- **Genre:** 3D Platformer (side-scrolling), Puzzle
- **Status:** Prototype

## Gameplay

- **Side-scrolling perspective:** the camera follows the action from the side, 3D platformer style.
- **Two-character control:** play as a duo with distinct abilities; switch between them to solve traversal and combat challenges.
- **Key-based progression:** each floor has a key that must be found to unlock access to the next floor.
- **Puzzles:** floors combine platforming with puzzles that require using both characters' skills together.
- **Combat:** enemies block your path and must be dealt with to progress.

## Getting Started

### Prerequisites
- Unity Hub
- Unity `2022.3.62f3` (match the version used to create this project)

### Setup
1. Clone the repo
   ```
   git clone https://github.com/<your-username>/Lorchester.git
   ```
2. Open Unity Hub and click **Add project**, then select the cloned folder.
3. Open the project in the matching Unity version.
